# LatihasChocobo（TC版）

自動陸行鳥競賽 Dalamud 插件，針對 FFXIVSimpleLauncher（TC）環境調整。

## 使用方式

- 輸入 `/lc` 或 `/latihaschocobo` 開啟插件介面

## 功能

### 競賽自動化
- 自動加速、轉向、跳躍
- 自動使用道具（技能1），偵測欄位有道具時立即使用
- 自動使用技能2（體力 > 70% 或進度 > 75% 時，最短冷卻20秒）
- 低體力/路長時禁用超速加速；高體力/路長時強制加速（可設定）
- 競賽結束後自動點擊結果確認視窗
- 進入指定地點自動循環匹配（任務搜尋器延遲3秒點擊，避免載入未完成）
- **陸行鳥升至40級時自動停止循環並發出提示音**

### 障礙物偵測與迴避
- **紅陷阱（2005040）**：正前方近距離時跳躍起跳，起跳距離依當前速度與跳躍校正參數（見下方「跳躍時機自動校正」）動態計算，並依陷阱是否在上坡自動提早起跳；跳不過時依實際左右位置往反方向閃避（不是固定向左）
- **紫減速（2005039）**：依實際左右位置往反方向閃避
- **障礙怪物（3595 靜止 / 3596 移動）**：依實際左右位置往反方向閃避
- **特殊NPC（3597）**：主動靠近
- 偵測距離會依**當前移動速度**動態放大（越快偵測越遠），並依物件是否為「已確認」（賽道記憶中重複出現過）分級調整，避免近距離來不及反應或遠距離誤判
- **壞物件優先於好物件處理**：掃描時只有「實際能判斷出有效閃避方向」的壞物件才會搶佔最近目標，避免選到閃不到的物件而卡住

### 寶箱/加速偵測
- **藍加速（2005038）**、**黃/藍寶箱（2005024/2005025）**、**綠體力（2005041）**：主動靠近或跳躍拾取
- 幾乎正前方的好物件不會刻意轉向（順路自然撿到），偏側時才轉向靠近；已確認的好物件轉向偵測距離更遠

### 賽道記憶學習（新）
插件會在每場比賽自動學習賽道地形，累積資料後閃避與拾取的判斷會越來越準，不需要手動設定。

- **物件與路點記錄**：每場比賽記錄障礙物/寶箱位置與玩家行進路點（含朝向），同一位置在不同場次重複出現滿 2 次後視為「已確認」，避免單場雜訊（殘影、瞬時物件）誤判；已確認物件會套用更寬鬆/更積極的距離與角度門檻。
- **邊界校正模式**：在「賽道」分頁一鍵觸發「開始邊界校正」，插件自動連跑 2 場（第1場全程靠左、第2場全程靠右）記錄賽道左右邊界線，跑完自動關閉。之後正常比賽時，只要玩家距離邊界不到 5 單位就會自動往內修正方向，避免掉出賽道或卡牆。
- **有序路徑追蹤**：把已確認路點依南到北、依朝向串成一條有序賽道路徑；當前方沒有即時可判斷方向的目標時，優先靠近記憶中前方已確認的好物件，否則沿著記憶路徑修正方向，減少迷路、走錯彎道。
- **賽道進度計算**：用記憶路徑的實際 3D 距離估算「已行進%/剩餘距離/總長度」，比遊戲內 UI 給的百分比更精確，用於技能2施放時機與 UI 顯示；資料不足（賽道總長 <200u）時自動退回 UI 百分比。
- **跳躍時機自動校正**：記錄每次跳躍按下到落地的完整弧線（最高點時間、最高點相對起跳點的高度），用指數移動平均持續微調，隨著比賽場次增加，紅陷阱的起跳時機會越來越準，也會依陷阱是否位於上坡自動提早起跳。
- **對手路徑補強**：追蹤場上對手陸行鳥（DataId 3705）的位置作為額外路點來源，因為對手一定跑在賽道上，能補齊玩家自己還沒走過的路段資料。
- 「賽道」分頁功能：
  - 路線圖（自動旋轉90°顯示，含賽道路線帶、左右邊界線、已確認/未確認路點、好壞物件位置、玩家與對手即時位置與朝向箭頭）
  - 坡度剖面圖（依路徑距離顯示地形高低起伏、陷阱位置、玩家目前位置）
  - 各賽道（389/390/391）資料統計（物件/路點/路徑總長）、逐一清除
  - 資料檔路徑顯示、開啟資料夾、複製路徑
- 資料存於插件設定資料夾的 `track_memory.json`，可將整份檔案或用插件的匯入功能與其他玩家交換賽道資料（匯入時同一物件/路點取兩邊出現次數的較大值合併，不會重複累加）。

### 資訊顯示
- 當前等級、經驗值（含上場獲得）、剩餘訓練次數
- 各屬性培育百分比（最高速度/加速力/體力/持久力/適應力）
- 先天/後天技能名稱
- 是否超速、是否可用道具、加速狀態
- 背包配種/出賽登記書星級分析
- 物件偵測頁（顯示附近所有物件 DataId，用於識別新障礙）
- 即時速度（u/s）、跳躍峰值時間/高度校正值

## TC 相關調整
- 材質路徑不含 `_hr1` 後綴（例如 `070101.tex`、`tc/180043.tex`）
- 已修正道具可用判斷、超速偵測材質路徑

## 需要手動設定的部分

### 1. 按鍵綁定（必要）
插件透過模擬按鍵操作遊戲，**必須確認遊戲內按鍵設定與插件「按鍵」頁面的 VK code 一致**。
- 預設假設 W=前進、A=左、D=右、Space=跳躍、1=技能1、2=技能2
- 若遊戲按鍵不同，在「按鍵」頁面填入正確的 [Windows VK code](https://learn.microsoft.com/en-us/windows/win32/inputdev/virtual-key-codes)

### 2. 技能欄位配置（必要）
- 技能1（KC_1）：賽道道具格，需對應到會使用當前持有道具的按鍵
- 技能2（KC_2）：建議對應高速衝刺或體力相關技能

### 3. 任務搜尋器選擇任務（使用自動匹配功能時）
插件只能自動**開啟任務搜尋器並點擊加入按鈕**，**無法自動選擇要報名的競賽項目**。
- 首次使用前，請先手動開啟任務搜尋器，選好陸行鳥競賽項目
- 之後插件的「立刻匹配」或自動循環才能直接點加入

### 4. 自動循環區域（使用自動匹配功能時）
「循環區域」欄位需填入**離開競賽後會回到的地點 TerritoryType ID**（用 `|` 分隔多個）。
- 可在插件主介面「當前區域」查看目前的 TerritoryType
- 競賽場地本身（389/390/391）不需填入，插件會自動偵測

### 5. 遊戲視窗
插件透過 `SendMessage` 傳送按鍵，**遊戲視窗不需要在最前面**，但必須保持開啟（不能最小化）。插件執行中會自動將遊戲視窗設為前景以確保按鍵訊息不被忽略。

### 6. 「滿級模式」選項
若陸行鳥已滿級，勾選「滿級模式」可放寬障礙迴避距離判斷（從14→20、22→30），更積極地接近好物件。
