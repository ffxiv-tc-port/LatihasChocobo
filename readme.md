# LatihasChocobo（TC版）

自動陸行鳥競賽插件。指令：`/lc`、`/latihaschocobo` 開啟插件介面。

## 功能

- **競賽自動化**：自動加速、轉向、跳躍、使用道具與技能、確認結果視窗；可依設定的地點自動循環報名比賽（陸行鳥滿 40 級時自動停止並發出提示音）
- **障礙迴避**：自動偵測陷阱、減速區、障礙怪物並主動迴避，主動靠近加速道具、寶箱與體力回復物件
- **賽道記憶學習**：逐場自動累積賽道地形、邊界與路徑資料，迴避與拾取準確度隨場次增加而提升；資料可匯出/匯入與其他玩家交換
- **賽道視覺化**（「賽道」分頁）：路線圖、坡度剖面圖、各賽道資料統計
- **即時資訊顯示**：等級、經驗值、培育屬性、技能、速度、道具與加速狀態等
- **物件偵測頁**：顯示附近所有物件 DataId，方便識別新障礙

## 設定需求

- 「按鍵」頁需與遊戲內按鍵設定一致（插件透過模擬按鍵操作遊戲）
- 技能欄位需對應道具格與衝刺技能
- 使用自動循環報名前，需先手動在任務搜尋器選好競賽項目，並填入離開賽場後會回到的地點
